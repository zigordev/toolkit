# Tools

Every tool of the platform is listed here once, 95 in all, each with what it is, exactly what we use it for, and where it runs. A tool that is not on this page is not part of the platform, and adding one waits for the owner.

The platform is built in eight phases, so many of these tools are not in use yet. The [reading order](README.md) of the handbook says which pieces exist.
